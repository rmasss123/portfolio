ENGINEERING INTERN · BENGALURU · JAN 2026 — PRESENT

SCORE

Project Gangajal — giving every call a score

Before this, counselors' calls were a black box. Managers could audit maybe 3% of them manually. I built Gangajal — an LLM pipeline on OpenAI + LangChain that scores every single call against quality rubrics, runs on AWS EC2 via automated cron jobs, and writes structured results to BigQuery. The black box opened.

OpenAILangChainEC2 · cronBigQuery
TRANSLATE

Breaking the language wall

Students speak Tamil, Telugu, Hindi, Marathi. The pipeline didn't. I extended Gangajal with LLM-powered transcript translation across four regional languages, with retry logic and fault-tolerance baked in. Coverage went from partial to 100% of all calls — no conversation left unheard.

GPT-4.14 languagesfault-tolerant
DETECT

The early warning system — catching churn before it happens

By the time a student stops responding, it's usually too late. I built an LLM analysis layer over WhatsApp conversations that reads between the lines — detecting frustration, confusion, and disengagement early, so counselors can step in while the relationship is still warm.

LLM analysisrisk signalsproactive ops
SERVE

Rebuilding the foundation — platform migration

The analytics dashboard was a Streamlit prototype on Postgres. I migrated it to a proper Next.js + FastAPI product backed by BigQuery, and rewrote the data layer with multi-CTE SQL pipelines using window functions — tracking the counselling funnel, visa timelines, and lead attribution end-to-end.

Next.jsFastAPIBigQuerySQL · CTEs
PREDICT

Who's actually going to convert?

Not all leads are equal. I trained a LightGBM model on profile data, counselor-interaction signals, and app engagement — then used SHAP to make the predictions explainable. Now counselors see a ranked queue every morning, with the highest-intent students at the top.

LightGBMSHAPfeature engineering

Building the world's colleges into a database

The College Finder product needed data on every university a student might consider. I built a Playwright-powered scraping system that assembled a hierarchical database of 1,000+ institutions and 100,000+ courses — the knowledge base underneath the product.
